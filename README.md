# My Dalamud Plugins

自作Dalamudプラグインのカスタムリポジトリです。

## 追加方法
1. ゲーム内で `/xlsettings` →「Experimental」タブ →「Custom Plugin Repositories」に次のURLを追加して保存
   ```
   https://raw.githubusercontent.com/visha-svg/MyDalamudPlugins/main/pluginmaster.json
   ```
2. `/xlplugins` からプラグインを検索してインストール

## プラグイン
| 名前 | 内容 |
|---|---|
| Mini Boss | 登録した敵（ボス）の見た目だけを縮小表示。当たり判定・AoE表示は変わりません。`/miniboss` または `/mb` で設定 |
| Quick Synth Queue | 選択したレシピの簡易製作をまとめて予約できます。「素材で最大」で手持ち素材から回数を入力できます。1バッチは最大99回です。耐久度0%の装備を自己修理するオプションがあります。数量画面の「＋／−」の上にある `qsqueue` ボタン、`/qsq`、`/qsqueue` で開きます |

※ Dalamudプラグインは外部ツールです。利用は自己責任でお願いします。
